# PROMPT QUEST — دليل الإعداد والنشر المجاني

هذه نسخة أولية جاهزة للنشر، وتعمل على الهاتف والكمبيوتر. الواجهة باللغة الإنجليزية لتناسب نشاط التدريب.

## ما الذي تتضمنه؟
- 6 تحديات لتصنيف البرومبتات إلى Weak / Strong.
- ستة مفاتيح: ROLE, CONTEXT, TASK, CLARITY, CONSTRAINTS, OUTPUT.
- 10 نقاط للإجابة الصحيحة و5 نقاط إضافية لاختيار عنصر البرومبت الصحيح.
- ستة فرق افتراضية، ورمز جلسة ورمز مستقل لكل فريق.
- لوحة ترتيب مباشرة عند تحديث النتائج.
- مهمة ختامية لحفظ البرومبت المحسّن لكل فريق.

## الخطوة 1 — إعداد Supabase
1. افتح https://supabase.com/dashboard وأنشئ مشروعاً جديداً.
2. اختر كلمة مرور قوية لقاعدة البيانات واحتفظ بها لنفسك.
3. افتح SQL Editor ثم New query.
4. انسخ محتويات الملف `supabase_setup.sql` والصقها ثم اضغط Run.
5. هذا ينشئ جلسة `AZHAR26` والفرق `TEAM01` إلى `TEAM06`.
6. يمكنك تغيير رموز الجلسة والفرق في نهاية ملف SQL قبل تشغيله. لا تشارك أي مفاتيح سرية.

## الخطوة 2 — الحصول على بيانات الربط
من Supabase افتح Project Settings → API.
انسخ:
- Project URL
- anon / publishable key

لا تنسخ `service_role` key ولا تشاركه أبداً.

## الخطوة 3 — رفع المشروع إلى GitHub
1. أنشئ Repository جديداً باسم `prompt-quest`.
2. اجعله Public (الكود لا يحتوي على أسرار).
3. ارفع جميع ملفات هذا المشروع إلى المستودع، مع الحفاظ على المجلد `src`.

## الخطوة 4 — النشر المجاني على Cloudflare Pages
1. افتح https://dash.cloudflare.com/ ثم Workers & Pages.
2. اختر Create → Pages → Connect to Git.
3. اربط حساب GitHub واختر مستودع `prompt-quest`.
4. Framework preset: Vite.
5. Build command: `npm run build`
6. Build output directory: `dist`
7. قبل النشر أو من Settings → Variables and Secrets أضف:
   - `VITE_SUPABASE_URL` = Project URL
   - `VITE_SUPABASE_ANON_KEY` = anon / publishable key
8. اضغط Save and Deploy.

بعد نجاح النشر سيظهر رابط عام ينتهي عادة بـ `pages.dev`.

## ملاحظات مهمة
- هذه نسخة MVP مناسبة لتجربة تدريبية. رموز الفرق مشتركة بين أعضاء الفريق.
- لا تجمع أسماء الطلاب أو بيانات شخصية.
- احتفظ برمز الجلسة والفرق للمتدربين، ولا تشارك لوحة Supabase أو مفاتيح الإدارة.
- نظام النقاط في هذه النسخة مناسب لنشاط تدريبي ودي، وليس مسابقة عالية الحساسية؛ يمكن تحسين التحقق من الإجابات على الخادم في مرحلة لاحقة.
- الخطة المجانية لدى أي مزود قد تتغير ولها حدود استخدام أو خمول. تحقق من حدود الخطط قبل اعتمادها لفعالية كبيرة.
